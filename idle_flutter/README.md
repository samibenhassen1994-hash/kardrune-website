## Flame PvP visual preview

Open `/idle/`, enter **Tournament PvP**, and tap **TEST FLAME** beside the live match button. The preview runs offline with two original character cards. **REPLAY** restarts the scripted attack, counterattack, damage and HP sequence; **NEXT PAIR** switches between Sam/Dren (sword/dagger) and Aria/Rhea (magic/arrow); **SOUND ON/OFF** controls the short synthesized effects; **BACK TO PVP** returns to Tournament. It does not create a match, change saves or grant rewards.

For the iPhone PWA check, reopen the installed app after the new release is available, apply its update prompt if shown, then use TEST FLAME and REPLAY several times. Observe responsiveness and animation smoothness on the device. iPhone frame rate and WebKit performance have not been measured by this build.
